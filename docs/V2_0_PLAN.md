## 第 1 轮：动画引擎 + 互动和情绪

**动画引擎**（新文件 `pet_motion.py`，纯计算，不依赖 Qt，可单测）
- 显示时 60 帧刷新（`Qt.PreciseTimer`，按真实经过的时间计算，不按帧数）；隐藏、关掉「动画」开关或者全屏游戏时停掉。
- 呼吸：以脚底为中心，竖向轻微伸缩、横向反向补偿（体积不变），每个动作有自己的呼吸速度和幅度（睡觉慢而深，开心快）。
- 弹簧物理：挤压/拉伸、倾斜、小跳都是阻尼弹簧，给一个冲量就自然回弹，不是写死的关键帧。
  - 单击：身体被戳一下，挤压回弹。
  - 拖动：以抓住的位置为支点，身体跟着鼠标速度惯性摆动，松手后落地挤压再弹回来。
  - 开心类动作（庆祝、比心、被摸头）：小跳一下。
- 切换动作时新动作立刻出现、旧动作多出来的边缘在约 0.14 秒内淡掉，同时轻微挤压，不再「啪」地换图，也不会出现半透明重影。
- 帧序列：每个动作在资源表里写自己的帧率和是否循环（循环 / 播一遍停在最后一帧），按时间播放。
- 眨眼：每 2～6 秒随机眨一次，20% 概率连眨两下；有 `<动作>_blink.png` 才眨。

**互动**
- 鼠标在头顶来回划 → 被摸头；摸太久 → 害羞。
- 单击 → 照旧打开面板，同时有被戳的回弹。
- 长按不动约 0.7 秒 → 撒娇（不打开面板）。
- 拖动 → 被拎起来；松手 → 落地。
- 连续戳、拖来拖去 → 鼓脸小生气。

**情绪引擎**（新文件 `pet_mood.py`）
- 优先级：被拖动 > 通知反应 > 你和她的互动 > 任务状态（打字、AI 工作中、听歌）> 心情。高优先级来了立刻打断低优先级。
- 心情由时间、你在不在、最近有没有互动决定：早上第一次打开 → 早安；深夜 → 打哈欠、晚安；很久没任务也没操作 → 无聊、偷看你、撒娇；免打扰或深夜长时间无操作 → 睡着，有操作就醒来伸懒腰；离开很久回来 → 张开双臂欢迎。
- 粘人程度（设置里）：安静 = 不主动做小动作，只会睡觉和醒来；适中 = 偶尔；黏人 = 更频繁，还会主动撒娇要你理她。
- 全屏和游戏时不主动做动作。

## 第 2 轮：专注陪伴模式

- 右键菜单和面板里「开始专注」：25 / 45 / 60 分钟或自定义，可选关联项目和待办。
- 专注中她安静看书（`focus_read`），不弹非紧急通知（审批卡片照常弹，可设置成只亮小标记）；休息时喝茶（`focus_tea`），提醒起来活动。
- 结束时举着小本子（`focus_done`），卡片显示这段时间：完成的待办、AI 完成的任务、改了哪些文件、用了多少 token。
- 记录进数据库（`focus_sessions`），周报里加一栏专注时长。

## 第 3 轮：项目预设 + 续工卡

- **项目预设**：每个项目可以存一个「开工方式」：用哪个 AI、模型、强度、文件夹、开场提示词。工作台项目旁边一个「开工」按钮，一键打开终端（复用快速派活）。
- **续工卡**：回到一个项目时（打开它的终端或者在工作台选中它），她举着卡片（`hold_card`）显示「上次做到哪」：上次的任务摘要、没完成的待办、被打断的任务；如果项目里有 `HANDOFF.md` 也读出要点。离开项目时可以随手记一句「下次从哪继续」。
- 卡片可关、可设置成不自动出现。

## 第 4 轮：用量目标 + 待办验收 + 点数和贴纸

- **项目用量目标**：每个项目可以设每周 token 或金额目标。到 80% 她会担心（`worried`），到 100% 提醒一次；一周都没超出 → 得意（`proud`）。目标进度显示在工作台和周报里。
- **待办「等你验收」**：交给 AI 的待办做完后不直接打勾，而是进入「等你验收」，显示 AI 做了什么，两个按钮：「通过」（打勾）和「再做一次」（填一句要改什么，带着原任务重新交给 AI）。
- **陪伴点数和纪念贴纸**：点数来自完成待办、完成专注、按时休息、验收通过，**不按 token 消耗算**。达成里程碑得贴纸（第一个项目完成、第一份周报、连续 7 天专注、完成 100 个待办……）。新增「收藏」页：点数、贴纸墙、获得日期。拿到贴纸时她鼓掌（`clap`）。

## 第 5 轮：收尾和发布

- 全部测试、性能检查（60 帧下 CPU 占用要低，隐藏时为零）、安装包升级测试（从 1.7.1 升到 2.0，数据库自动升级前先备份）。
- 更新 README、发布说明、ARTWORK.md。
- 你验收通过并授权后发布 v2.0.0。

## 每轮验收看什么

- 第 1 轮：她是不是一直在「动」（呼吸、眨眼、淡入淡出）；摸头、戳、长按、拖动、松手的反应；深夜、无聊、睡着、醒来；粘人程度三档的差别；CPU 占用。
- 第 2 轮：专注开始、休息、结束卡片的内容。
- 第 3 轮：一键开工；回到项目时的续工卡。
- 第 4 轮：目标 80% / 100% / 一周达标；验收通过和再做一次；点数、贴纸、收藏页。
