# V1.6 提醒与通知 · 验收清单

## 1. 预览（安全，不读取你的数据）

双击 `预览-1.6.cmd`。左边的控制面板最下方有「Send test notification / 发送测试通知」。

- [ ] 选 `finished` 点发送：右下角弹出「任务完成」通知，桌宠欢呼几秒后恢复。
- [ ] `failed`：弹出「任务出错了」，桌宠难过。
- [ ] `needs_approval`：弹出「在等你确认」，桌宠挥手。
- [ ] `quota_low`：弹出「5 小时额度只剩 18%」。
- [ ] `reminder`：弹出「提醒」。
- [ ] 点击弹出的通知：打开对应任务的详情，或者打开工作台的「通知」页。
- [ ] 工作台 →「通知」页：上面几条都在，可以按类型筛选；「个人提醒」可以添加和删除。
- [ ] 「Pet fixture / 桌宠状态」下拉框里能选 celebrate / sad / wave 三个新动作。
- [ ] 设置里有「Claude 即时通知」「免打扰」「定时免打扰」；打开「免打扰」后再发送测试通知，不弹窗、桌宠不动，但「通知」页里仍然有记录。

## 2. 真实使用（可选）

直接运行 `petoken.exe`。

- [ ] 设置 → 打开「Claude 即时通知」→ 保存。在 Claude 桌面版或终端让 Claude 做一件小事，回复完成后 1 秒左右弹出通知。
- [ ] 在一个需要你点「允许」的 Claude 会话里（非自动允许模式），Claude 请求权限时弹出「在等你确认」。
- [ ] 让 Codex 跑一个任务，结束后几秒内弹出「Codex 任务完成」。
- [ ] 关掉「Claude 即时通知」并保存后，Claude 设置里只移除了 Petoken 加的部分。

有问题截图发给 Claude 即可。
