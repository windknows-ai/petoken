# Petoken v2.5.2

**English** · [中文](#中文)

## English

Stardust for keeping her company.

### Added

- **+10 stardust for every 5 minutes Petoken runs.** It comes on top of what work earns (the daily work limit of 600 does not apply to it) and shows in the stardust record as "Petoken running". The ways to earn stardust on the Milestones page list it too.

### Install

Download `Petoken-Setup-v2.5.2.exe`, check it against `SHA256SUMS.txt`, and run it. Petoken 2.x updates itself when automatic updates are on.

## 中文

陪着她也能攒星辉。

### 新增

- **Petoken 每运行 5 分钟 +10 星辉。** 和工作所得分开计算（不受工作每天最多 600 的限制），在星辉记录里显示为「Petoken 运行时长」；里程碑页的获得方式里也写上了。

### 安装

下载 `Petoken-Setup-v2.5.2.exe`，用 `SHA256SUMS.txt` 核对后运行。打开自动更新的 Petoken 2.x 会自己更新。
