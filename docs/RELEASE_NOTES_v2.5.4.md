# Petoken v2.5.4

**English** · [中文](#中文)

## English

### Changed

- The usage card now also clears the star ring around her: it sits above the ring when the ring reaches higher than her head.

### Install

Download `Petoken-Setup-v2.5.4.exe`, check it against `SHA256SUMS.txt`, and run it. Petoken 2.x updates itself when automatic updates are on.
