# Petoken 2.0 角色动作清单（陪伴感）

> **2.0 动作以 [V2_0_ART_PROMPTS.md](V2_0_ART_PROMPTS.md) 为准**：每个动作重新画全身姿势（不再在 idle 上局部修改），帧数、眨眼图和提示词都在那里。本文件里的配饰、摆件和贴纸要求仍然有效。

Petoken 2.0（路线图上原本的 1.8「陪伴感」阶段）让人物更有生命力：会撒娇、会被摸头、会睡觉打哈欠、会陪你专注、会对用量目标着急或得意。下面是需要新画的动作，由 Codex 绘制，Claude 接入程序。

## 一、通用要求（每一张都必须满足）

- **同一个角色**：以 `assets/v1_1/idle.png` 为标准，银紫色头发、冰蓝色点缀、原有服装，Q 版比例和五官画法不变。只改变姿势、表情和小道具，不换衣服，不加新角色。
- **画布**：1254×1254 像素，PNG，**真正的透明背景**（alpha 通道），不能有棋盘格、纯色底或阴影底。
- **站位**：脚底（或坐姿时的底部）和 `idle.png` 在同一条基线上，人物大体居中。这样切换动作时人物不会跳动。
- **小尺寸也要看得懂**：桌宠实际显示大约 128～200 像素，表情和动作要夸张、轮廓清楚，细节不要太碎。
- **图里不要有文字**：不要写字，不要气泡里的字。符号可以有（心形、Zzz、小汗滴、问号、星星）。卡片和本子上要留空白，文字由程序画。
- **多帧动作**：文件名是 `<名称>_1.png`、`<名称>_2.png`……，所有帧用同一张画布、同一条基线，只有动的部分不同（比如头点一下、手摆一下），这样循环播放才不会抖。
- **文件位置**：全部放在 `assets/v2_0/`，文件名用下表里的英文名。不要修改 `assets/v1_1/` 和 `assets/*.png` 里已有的图（`skirk-pet.png` 有校验）。
- **先给样张**：正式画全部之前，先画 3 张样张（`coquettish`、`headpat_happy`、`sleep`），连同 `idle.png` 拼成一张对比图，交给维护者确认风格，确认后再画其余的。

## 二、动作清单

优先级：**P0** = 2.0 核心功能必须有；**P1** = 有了更好，可以第二批；**P2** = 装饰类，可以以后再做。

### E. 成长和装饰（P2，可以以后再做）

成长来自完成待办、专注和按时休息，**不按消耗的 token 多少来升级**，避免鼓励无意义的使用。

| 类型 | 规格 | 内容 |
|---|---|---|
| 配饰图层 | 1254×1254 透明 PNG，**和 `idle.png` 完全对齐**，只画配饰本身（其余全透明），文件名 `accessory_<名称>.png` | 贝雷帽 `beret`、围巾 `scarf`、圆眼镜 `glasses`、花朵发夹 `hairpin`、猫耳耳机 `cat_headphones` |
| 桌边摆件 | 512×512 透明 PNG，`desk_<名称>.png`，和人物同样的画风和配色 | 小盆栽 `plant`、咖啡杯 `mug`、一摞书 `books`、星星台灯 `lamp` |
| 纪念贴纸 | 256×256 透明 PNG，圆形或徽章形，`sticker_<名称>.png`，不要文字 | 第一个项目完成 `first_project`、第一份周报 `first_weekly`、完成 10 轮专注 `focus_10`、连续 7 天专注 `streak_7`、一周没超出用量目标 `goal_week`、完成 100 个待办 `todos_100`（没有图时程序先画一个圆形徽章代替） |

## 三、交付

1. 先交 3 张样张和对比图，等维护者确认风格。
2. 确认后按优先级交付：P0 全部 → P1 → P2。
3. 每一批附一张总览图（所有新动作和 `idle.png` 并排），放在 `docs/V2_0_ART_PREVIEW.png`（`docs/` 不会被打进安装包）。
4. 自检：每张图都是 1254×1254（贴纸、摆件按上面的尺寸）、真透明背景、和 `idle.png` 的基线一致、多帧之间对齐、图里没有文字。
5. 写明每张图的生成方式（和 `docs/ARTWORK.md` 已有的说明保持一致），Claude 会把它补进 ARTWORK.md。
