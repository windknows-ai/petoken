# Petoken v2.0.4

A cleaner usage card, and focus breaks that wait for you.

- **The usage card shows only the account limits.** The card above her head
  no longer has a context ring: the 5-hour and weekly limits are account-wide,
  while context belongs to a single task. The two remaining gauges are bigger,
  with the label and the reset time beside each ring. A task's context is still
  in the usage panel, and when it is nearly full you still get a notification;
  it is just no longer a line on the card.
- **Focus and breaks wait for you.** When the focus time is up she shows the
  summary and waits; the break starts only when you press OK (or Start break at
  her feet). When the break time is up she waits again until you press OK.
  Ending early still skips the break.
- Petoken's own tests no longer leave temporary folders behind.

v1.7.0 and later offer this update by themselves (Settings > General >
Updates). Otherwise download `Petoken-Setup-v2.0.4.exe` and verify it against
`SHA256SUMS.txt` from the
[GitHub release](https://github.com/windknows-ai/petoken/releases/tag/v2.0.4).

# Petoken v2.0.4（中文）

用量卡片更清爽，专注后的休息等你点了才开始。

- **用量卡片只显示账户额度。** 她头顶的卡片去掉了「上下文」圆环：5 小时和一周额度是整个账户的，而上下文只属于某一个任务。剩下的两个圆环变大了，名称和重置时间放在圆环旁边。每个任务的上下文仍然在用量面板里；上下文快满时照样会通知你，只是不再写在卡片上。
- **专注和休息都等你确认。** 专注时间到了，她会给出总结并等你；点「好的」（或她脚下的「开始休息」）休息才开始。休息时间到了也一样，点「好的」才回到平常。提前结束专注仍然不会进入休息。
- Petoken 自己的测试不再在临时文件夹里留下垃圾。

v1.7.0 及以后的版本会自己提示这次更新（设置 → 常规 → 更新）。也可以在 [GitHub 发布页](https://github.com/windknows-ai/petoken/releases/tag/v2.0.4) 下载 `Petoken-Setup-v2.0.4.exe`，并用 `SHA256SUMS.txt` 核对。
