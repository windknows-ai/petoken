# 星辉衣柜美术（给 Codex）

## 背景

Petoken 2.5 的「星辉衣柜」是一个独立窗口（`wardrobe.py`）：
- 左边一面试衣镜，她站在里面试穿；
- 右边是衣柜内部，物品一件件摆在层板上；
- 打开时两扇衣柜门向两边打开。

现在这些都是程序画的，不够精致。请画一套衣柜美术。程序会自动读取 `assets/v2_5/wardrobe/` 里同名的图，读到就用你的，读不到才用程序画的版本。

## 风格

- **整体：** 和你已经画的 60 件装饰、20 把武器、星海形态一致。梦幻、精致、夜空主题。
- **主色：** 夜蓝、紫罗兰、冰蓝、珍珠白。
- **点缀：** 香槟金和银色的金属描边、细金丝花纹、星星和月牙纹样，小颗水晶和宝石。
- **线条：** 干净，有手绘质感，不要写实木纹那种厚重感。
- **透明度：** 所有 PNG 都是 RGBA 真透明，边缘干净，不带底色，也不带文字。
