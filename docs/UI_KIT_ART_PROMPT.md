# Petoken 界面美术套件（给 Codex）

## 背景

Petoken 的界面正在换成 Qt Quick（GPU 渲染）重做，目标是像一个真正的游戏内 App，而不是色块堆出来的窗口。星辉衣柜已经用你画的衣柜美术重做好了。下一步重做工作台（首页、待办、便签、项目、通知、报告、收藏、指南）和设置。

程序负责布局、文字、动画和数据，你负责画「材质」和插画。

## 风格

- **整体：** 和星辉衣柜那一套保持一致。梦幻夜空主题，主色夜蓝和紫罗兰，香槟金和银色金属描边，星星、月牙、水晶点缀。
- **反差：** 工作台每天要看很久，比衣柜收敛一些。装饰集中在边角和标题处，内容区域保持干净、留白充足，方便放文字。
- **透明度：** 全部是 RGBA 真透明 PNG，边缘干净。
- **文字：** 图里不要有任何文字。
