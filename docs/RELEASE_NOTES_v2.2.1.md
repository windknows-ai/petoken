# Petoken v2.2.1

- **Notices name short tasks too.** A Claude Code run that finished within a
  few seconds was announced with only its folder (for example "Documents ·
  no files changed"). Petoken now remembers each task's name as soon as it
  appears, and otherwise reads it from Claude Code's records, so the notice
  says "reset · Documents", on the desktop and on the phone.

v1.7.0 and later offer this update by themselves (Settings > General >
Updates). Otherwise download `Petoken-Setup-v2.2.1.exe` and verify it against
`SHA256SUMS.txt` from the
[GitHub release](https://github.com/windknows-ai/petoken/releases/tag/v2.2.1).
Everything in [v2.2.0](RELEASE_NOTES_v2.2.0.md) is unchanged.

# Petoken v2.2.1（中文）

- **几秒就做完的任务，通知里也有任务名。** 以前几秒内做完的 Claude Code 任务，通知里只写文件夹名（比如「Documents · 没有改文件」）。现在任务一出现就记住它的名字，没记到的话再去 Claude Code 的记录里找，桌面和手机通知都会写成「reset · Documents」。

v1.7.0 及以后的版本会自己提示这次更新（设置 → 常规 → 更新）。也可以在 [GitHub 发布页](https://github.com/windknows-ai/petoken/releases/tag/v2.2.1) 下载 `Petoken-Setup-v2.2.1.exe`，并用 `SHA256SUMS.txt` 核对。v2.2.0 的其他内容不变。
