# 用量模型（概念版）

> 本文档讲“算什么、展示什么”，不讲“代码怎么算”。数字口径以应用内 tooltip 与发布说明为准。

V1.3.0 仅支持 Codex。下方 OpenCode 部分保留为历史 v1.2.0 口径记录，不是当前程序的可选来源；不会启动其适配器或读取其数据库。

## Codex（一句话口径）

- 显示官方 `total`；缓存输入与推理输出是输入 / 输出的子集，**不重复计入总量**。
- 派生指标（新增工作量、缓存命中率、输出占比、推理占比）分母无效或字段缺失时显示 `N/A`。
- 费用 = 基于记录模型与档位的 API 等价估算，可选 USD / CAD / EUR / CNY；是估算，不是订阅账单。
- 额度 = 官方 5 小时 / 每周读数与重置倒计时。

## 历史 OpenCode 口径（v1.2.0）

- 显示 Input / Output / Reasoning / Cache Read / Cache Write 五个原始分类，互不加总、不假设包含关系。
- Total 仅在“已验证版本（1.18.31 / 1.18.32）且数据完整”时显示记录值（五类之和），其余情况为 `N/A`；它不是账单，也不是上下文窗口。
- 费用 = 工具已记录金额，币种未知，不做换算与符号推断。
- 无额度、无重置计时：OpenCode 模式下相关 UI 会隐藏，而不是显示假数据。

## 通用诚实规则

1. 未知显示 `N/A`，绝不填零、绝不编造。
2. 不做跨提供方合并统计（Codex 与 OpenCode 各自独立）。
3. 累计计数器转增量；无法归属的历史量记为“未归属”，不摊到当天或当前模型。
4. 日历范围按系统本地时区；本地 lifetime 仅覆盖本机留存记录，不声称服务端全量。
