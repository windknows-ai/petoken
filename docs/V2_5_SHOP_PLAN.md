# 2.5 草案 · 星辉商店

> 本版（2.4）的宣传片和说明都不提商店；商店是下一版的内容。

## 已定（用户 2026-10-11）

1. **两套星辉**
   - **累计星辉**：只增不减，决定里程碑奖励（现在三个：流星星环 150、极光星环 400、星海形态 1000，以后用户再加）。
   - **可用星辉**：商店里花的钱；花掉不影响已解锁的里程碑。
2. **稀有度**（低 → 高）：繁星 / 明月 / 皓日 / 银河 / 星海。价格和稀有度成正比。
   - 数量比例从高到低是 星海:银河:皓日:明月:繁星 = 1:3:9:18:27。
   - **星海级只能抽取获得**，不能直接买。
   - 里程碑里的星海形态算**银河级**。
3. **第一批：都做**（星环特效、任务星造型、主题配色、饰品），其中饰品请 Codex 画 **60 个部件**，参考抖音小火人和桌宠装扮类软件。
4. **流星、极光、星海形态不进商店**，仍是里程碑奖励。
5. **每日精选**：每天固定随机选 4 件；每件由用户自己抽一次折扣，结果在 6 / 6.5 / 7 / 7.5 / 8 / 8.5 / 9 / 9.5 折里随机，当天有效。

## 部件怎么挂到她身上（技术约束）

她有 90 多个动作，头的位置和身体朝向各不相同。所以第一批只做程序能稳定定位的几类：

| 类别 | 挂在哪 | 程序怎么定位 |
| --- | --- | --- |
| 头顶（帽子、王冠、耳朵、光环、发饰顶花） | 头顶 | 每帧图的不透明区域最上沿、靠头部中线的位置，自动算；躺着的动作（睡觉、被拖）自动隐藏 |
| 身后（翅膀、披风光、背后法器） | 她身后中央 | 身体中心，画在她后面 |
| 脚下（法阵、云朵、花丛、星座盘） | 脚下中央 | 每帧图的底部中线 |
| 漂浮伙伴（小精灵、小动物、灯笼） | 她身边 | 不贴身，在旁边轻轻飘 |
| 任务星造型 | 星环上的每颗任务星 | 替换现在的四角水晶星 |

眼镜、围巾这类贴在脸上、脖子上的饰品，需要给每个动作单独标位置，留到以后再做。
