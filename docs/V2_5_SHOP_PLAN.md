## 服装和武器怎么做（第三轮，2026-10-11）

- 用户要**真正能换款式**，并提出「从最高级反着画，每低一级遮掉一部分」。
- **服装 = 一套完整造型**，和星海形态的做法一样：每套画 22 张常用动作（待机 4 帧 + 眨眼、打字 3、庆祝 2、难过 + 眨眼、打招呼 2、思考 2、睡觉 2、摸头 2、被戳、被拖）；其他动作自动换成最接近的那张。
- **按「系列」反着画**：每个系列先画最高稀有度的完整版，低一级就去掉一部分（披肩、裙摆层、饰品……），其余像素完全不动，像觉醒阶段那样。
- 20 件服装 = 9 个系列，正好凑成 星海 1、银河 1、皓日 3、明月 6、繁星 9：
  - 系列 1：星海 → 银河 → 皓日 → 明月 → 繁星（5 件）
  - 系列 2、3：皓日 → 明月 → 繁星（各 3 件）
  - 系列 4、5、6：明月 → 繁星（各 2 件）
  - 系列 7、8、9：只有繁星（各 1 件）
- **武器**：每个动作标一次手的位置和角度（`hands.json`），每把武器只画一张图，程序挂到她手上；看不到手的动作自动隐藏。20 把，稀有度同样 1/1/3/6/9。
- **装饰**：Codex 正在按第一版提示词画 60 件（头顶 18、身后 10、脚下 10、伙伴 10、任务星 12；星海 1、银河 3、皓日 9、明月 19、繁星 28），画好后整套作为装饰类上架。

## 部件怎么挂到她身上（技术约束）

她有 90 多个动作，头的位置和身体朝向各不相同。所以第一批只做程序能稳定定位的几类：

| 类别 | 挂在哪 | 程序怎么定位 |
| --- | --- | --- |
| 头顶（帽子、王冠、耳朵、光环、发饰顶花） | 头顶 | 每帧图的不透明区域最上沿、靠头部中线的位置，自动算；躺着的动作（睡觉、被拖）自动隐藏 |
| 身后（翅膀、披风光、背后法器） | 她身后中央 | 身体中心，画在她后面 |
| 脚下（法阵、云朵、花丛、星座盘） | 脚下中央 | 每帧图的底部中线 |
| 漂浮伙伴（小精灵、小动物、灯笼） | 她身边 | 不贴身，在旁边轻轻飘 |
| 任务星造型 | 星环上的每颗任务星 | 替换现在的四角水晶星 |

眼镜、围巾这类贴在脸上、脖子上的饰品，需要给每个动作单独标位置，留到以后再做。
